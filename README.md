# ГЕРАНЬ-2М: УДАРНЫЙ РОЙ — 3D-симулятор оператора БПЛА

Веб-игра для мобильных устройств и ПК с видом от первого лица из оптико-тепловизионной ГСН барражирующего боеприпаса «Герань-2М» и камерой объективного контроля с БПЛА-разведчика «Орлан-30».

---

## Как запустить игру прямо с GitHub (GitHub Pages)

Проект собран с использованием `vite-plugin-singlefile` и процедурной 3D/аудио-генерации: у игры **нет внешних ассетов или бэкенда**, поэтому она работает на бесплатном хостинге **GitHub Pages** без единой правки путей и открывается по прямой ссылке с любого смартфона или ПК.

### Способ 1. Автоматическая компиляция на самом GitHub (даже без Node.js на компьютере)

В проект уже добавлен готовый сценарий **`.github/workflows/deploy.yml`**.

1. Создайте новый публичный репозиторий на [github.com/new](https://github.com/new) (например, `geran-drone`).
2. Загрузите в него все файлы этого проекта (через `git push` или перетаскиванием файлов в веб-интерфейсе GitHub, включая папку `.github/workflows/deploy.yml`).
3. Откройте вкладку **Settings** в вашем репозитории → в левом меню выберите **Pages**.
4. В пункте **Build and deployment → Source** переключите значение с `Deploy from a branch` на **`GitHub Actions`**.
5. Подождите ~45 секунд (статус сборки виден во вкладке **Actions**).
6. Готово! Игра будет круглосуточно доступна по ссылке вида:
   `https://<ваш-логин>.github.io/geran-drone/`

При любом следующем обновлении кода на GitHub новая версия игры скомпилируется и обновится по ссылке автоматически.

---

### Способ 2. Скомпилировать на своём ПК в один автономный `index.html`

Если у вас установлен [Node.js](https://nodejs.org/) (версия 18+):

```bash
npm install
npm run build
```

После этого в папке `dist/` появится **всего один самодостаточный файл `dist/index.html` (~980 КБ)**, внутри которого уже вшиты Three.js, шейдеры HDR Bloom, 3D-модели, сюжет и звуковой синтезатор!

С этим файлом можно сделать что угодно:
- **Выложить на GitHub Pages за 10 секунд**: загрузите только этот файл `index.html` в корень любого репозитория на GitHub и в **Settings → Pages → Source** выберите `Deploy from a branch` → ветка `main` (`/(root)`).
- **Играть офлайн / переслать в мессенджере**: файл `dist/index.html` открывается двойным кликом в любом браузере без интернета и серверов.

## Локальный запуск для разработки

```bash
npm install
npm run dev
```

## Автоматические тесты игровой логики

Тесты покрывают штурвал (мёртвая зона, сглаживание, приоритет указателя, защита от NaN), геометрию попадания в окно на высокой скорости, генератор «Свободной охоты» и целостность миссий:

```bash
./node_modules/.bin/esbuild tests/game-logic.test.ts --bundle --platform=node --format=esm --outfile=.test-dist/game-logic.test.mjs
node --test .test-dist/game-logic.test.mjs
```
